# Social carousel QA checklist

## Claims and compliance

- [ ] Every non-trivial claim is supported by IASME, NCSC or verified
  BrightCert product behaviour.
- [ ] The source URLs and retrieval date are recorded in the brief.
- [ ] Fees and regulatory wording match the current source.
- [ ] The official questionnaire is not reproduced verbatim.
- [ ] BrightCert is described as a readiness service, not a Certification Body.
- [ ] There is no pass guarantee, artificial urgency or unsupported metric.
- [ ] The final page contains the exact readiness disclaimer.

## Copy

- [ ] Page 1 works without the rest of the carousel.
- [ ] Any number promised on page 1 is exactly delivered.
- [ ] Every page has one main idea and normally fewer than 30 words.
- [ ] UK English is used.
- [ ] No jargon is left unexplained.
- [ ] No em dash appears in visible copy.
- [ ] There is one CTA only.
- [ ] Founder, company and Instagram captions are distinct.

## Design

- [ ] Canvas is 1080 x 1350 px on every page.
- [ ] Critical content stays inside the 60 px safe area.
- [ ] Body copy is at least 32 px and headings at least 48 px.
- [ ] Text remains legible at phone size.
- [ ] Contrast is sufficient on every page.
- [ ] Logo, source label and page number are consistent.
- [ ] No text is clipped, unexpectedly wrapped or overlapping.
- [ ] No generic stock cyber imagery, watermarks or borrowed screenshots.

## Export and publishing

- [ ] LinkedIn PDF pages are the same size and the file is below 100 MB.
- [ ] Seven Instagram PNGs are present and numbered in order.
- [ ] Derivative graphic is 1080 x 1350 px.
- [ ] Accessibility text exists for every Instagram page.
- [ ] LinkedIn first-comment and Instagram bio URLs use the agreed UTM fields.
- [ ] Founder approval is recorded.
- [ ] No post has been published or scheduled without owner approval.
